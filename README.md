# puff

The puff drinkware website. One page, with real 3D product renders and a live "View in 3D" viewer.

**Live site:** https://malaaknote4-bot.github.io/puff-perfume-/

- `index.html`, `styles.css` and `app.js`: the site. Product names, colors and copy are in `app.js` and `3d/colors.js`.
- `img/`: pre-rendered 3D product images.
- `3d/`: the 3D models, the viewer and the tools that re-render the images (see `3d/README.md`).
